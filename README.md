# OxGuess

A daily numbers game for everyone: five questions, guess on a slider, score by how close you get, and see how
the whole herd guessed. Named after the 1906 fair where a crowd guessed an ox's weight to within 1%.

- `docs/vision.md`: the game, the ox and herd theme, running product notes
- `docs/data-feasibility.md`: can we get enough good questions? (yes, via a question factory)
- `prototype/ballpark-v0.html`: first playable mock (single HTML file, simulated crowd)
- `scripts/explore/`: Wikidata exploration scripts (stdlib Python, QLever endpoint)
- `data/samples/`: raw exploration output
